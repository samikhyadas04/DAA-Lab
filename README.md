# LAB 1

| Q. No. | Question | Short Description |
|---|---|---|
| 1 | Put Them in Order | Arrange given growth-rate functions (e.g. n log₂n, 2ⁿ, n², √n, n^0.51, 3ⁿ, etc.) in increasing order of growth for large n |
| 2 | Fair vs Biased Coin | Simulate coin tosses to show fair coin P(HEAD) ≈ 0.5; extend to compare against biased coins and observe convergence |
| 3 | Performance Analysis of Bubble Sort | Compare early-terminating vs. always-full-pass bubble sort by counting comparisons on randomized data |
| 4 | Towers of Hanoi (ToH) | Simulate recursive ToH solution; plot moves vs. discs (n) and verify against the 2ⁿ−1 formula |
| 5 | Find the Partition Point | Find the exact transition index in a 0s-then-1s array using binary search |
| 6 | Element Uniqueness | Check for duplicates among n random numbers using sort-and-scan; analyze duplicate probability and timing as n grows large |
